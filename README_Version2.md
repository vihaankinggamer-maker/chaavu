# 💕 Valentine's Website for Chaavu 💕

A highly graphic, cute, and interactive Valentine's Day website created with love! 🥰

## Features ✨

### 🎯 Main Pages
- **Page 1**: Initial "Will you be my girlfriend?" question with cute GIFs
- **Page 2**: Confirmation page with adorable cat GIF  
- **Page 3**: Main experience hub with multiple interactive sections

### 🎮 Interactive Sections

#### 📸 Camera & Photo Booth
- Real-time camera access
- Cute stickers and overlays
- Photo capture and download functionality

#### 🎮 Games
- **Heart Match Game**: Match pairs of cute hearts
- **Heart Clicker**: Click hearts for points
- **Heart Cross Game**: Select correct hearts and level up
- **Memory Game**: Classic memory matching

#### 🎵 Music Player
- Advanced music player with animations
- Plays Terenaina 💕
- Volume control
- Progress bar

#### 🖼️ Gallery
- Memory gallery section
- Display your favorite moments

#### 💌 About Us
- Personalized love messages
- Cute animations and heart graphics

## 🚀 Deploy on Vercel

1. Go to [vercel.com](https://vercel.com)
2. Click "New Project"
3. Select this repository
4. Click "Deploy"
5. Share the link! 💕

## 🛠️ Local Development

```bash
python -m http.server 8000
# Visit http://localhost:8000
```

## 📁 Important

Make sure `terenaina.mp3` is in the same directory as the HTML file!
